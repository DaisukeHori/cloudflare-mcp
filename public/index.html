CTunnel接続（2）

cf_list_tunnel_connections cf_clean_tunnel_connections

DDNS管理（4）

cf_list_dns_records cf_create_dns_record cf_update_dns_record cf_delete_dns_record

Zゾーン管理（5）

cf_list_zones cf_get_zone cf_create_zone cf_delete_zone cf_get_zone_settings

Aアカウント（4）

cf_list_accounts cf_get_account cf_list_account_members cf_get_user

Wワークフロー（3）

cf_publish_hostname cf_unpublish_hostname cf_tunnel_status_summary

B課金（4）

cf_get_billing_profile cf_get_billing_history cf_list_account_subscriptions cf_get_billing_usage

RRegistrar（3）※制限あり

cf_list_r2_buckets cf_create_r2_bucket cf_get_r2_bucket cf_delete_r2_bucket cf_list_r2_objects

KKV Storage（5）

cf_list_kv_namespaces cf_create_kv_namespace cf_delete_kv_namespace cf_list_kv_keys cf_get_kv_value

公式コネクタとの比較

Cloudflare公式コネクタ（bindings.mcp）は接続不要。本MCPが全機能を包含

機能公式コネクタcloudflare-mcp
Tunnel管理✗✓ CRUD + ingress + token
DNS管理✗✓ CRUD
Zone管理✗✓ CRUD + 設定
Access (App/Policy)✗✓ App + Policy CRUD
Billing✗✓ プロフィール・履歴・サブスク
Registrar✗△ Global API Key必須（CF制限）
Workers△ 一覧+コード取得のみ✓ + デプロイ・設定・ルート
KV△ Namespace CRUDのみ✓ + キー一覧・値取得
R2△ バケットのみ✓ + オブジェクト一覧
Pages✗✓ プロジェクト + デプロイ + ロールバック
SSL/TLS✗✓ 設定・証明書
ワークフロー✗✓ publish/unpublish/summary

セットアップガイド

1

Cloudflare APIトークンを作成

ダッシュボード → APIトークン → カスタム トークンを作成する

トークン名: cloudflare-mcp

権限（「＋ さらに追加する」で1行ずつ追加）:
  アカウント | Cloudflare Tunnel  | 編集
  アカウント | Access: Apps       | 編集
  アカウント | Access: Policies   | 編集
  アカウント | Workers スクリプト   | 編集
  アカウント | Workers KV Storage | 編集
  アカウント | Workers R2 Storage | 編集
  アカウント | Cloudflare Pages   | 編集
  アカウント | アカウント設定       | 編集
  アカウント | 請求               | 編集
  ゾーン     | ゾーン             | 編集
  ゾーン     | ゾーン設定          | 編集
  ゾーン     | DNS               | 編集
  ゾーン     | SSL および証明書    | 読み取り

アカウント リソース: 含む > 自分のアカウント
ゾーン リソース: 含む > すべてのゾーン
2

Vercelにデプロイ

git clone https://github.com/DaisukeHori/cloudflare-mcp.git
cd cloudflare-mcp && npm install && npm run build
npx vercel --prod
3

環境変数を設定

MCP_API_KEY=cfmcp-your-random-key
CF_API_TOKEN=your-cloudflare-api-token
CF_ACCOUNT_ID=your-account-id
4

Claude.aiでコネクタ登録

https://cloudflare-mcp.vercel.app/api/mcp?key=YOUR_MCP_API_KEY
